# Meross Provisioner

Experimental Home Assistant app for provisioning Meross devices onto a Wi-Fi network without the Meross mobile app.

Read the **Documentation** tab before use. The app requires a wired Home Assistant connection, a dedicated Wi-Fi interface, and the slug of the access-point app. Its first use temporarily interrupts that AP. The local Meross setup protocol sends Wi-Fi credentials without encryption, and the hardware workflow has not yet been tested on a Raspberry Pi 5.
